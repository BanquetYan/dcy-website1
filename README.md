# 鼎程溢 DCY — GitHub Pages 網站

## 本機預覽
直接雙擊 `index.html` 即可用瀏覽器開啟。

## 你要先修改的資料
1. `index.html` 搜尋 `YOUR_EMAIL@example.com`，換成正式 Email。
2. 搜尋「請替換為你的 LINE 連結」與「請替換為你的電話」。
3. 將作品照片放到 `images/portfolio/`，再把作品卡片的 placeholder 改成 `<img src="images/portfolio/檔名.jpg" alt="作品名稱">`。
4. 公司 DM 放到 `files/`，可新增下載按鈕 `<a href="files/你的DM.pdf" download>下載公司DM</a>`。
5. 正式 Logo 可放到 `images/`，再替換頁首的 DCY 文字標誌。

## GitHub Pages 上線
1. 登入 GitHub，建立新的 Public repository，例如 `dcy-website`。
2. 將這個資料夾內的所有檔案上傳到 repository 根目錄。
3. 到 repository 的 Settings → Pages。
4. Build and deployment 選 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/ (root)`，按 Save。
6. 等待 GitHub 完成部署後即可取得網站網址。

如果 repository 名稱是 `<你的帳號>.github.io`，網址會直接是 `https://<你的帳號>.github.io/`。
一般 repository 則通常是 `https://<你的帳號>.github.io/dcy-website/`。
